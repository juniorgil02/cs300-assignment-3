# Assignment 3 Starter: JavaScript Data Toolkit

This folder is your starting point for Assignment 3. Copy everything inside it, not the folder itself, into your cloned `cs300-assignment-3` repository.

## What Is Here

- `toolkit.js`: your seven functions go here. The comments list them.
- `harness.js`: your named test cases go here. Right now it only prints a "Starter ready" message.
- `package.json`: lets Node use `import` and `export`. There is nothing to install.
- `SCENARIOS.md`: the four scenarios and their datasets. Pick one.
- `data/`: the four datasets (`books.json`, `events.json`, `games.json`, `resources.json`) and three test files for edge cases (`boundary-records.json`, `empty.json`, `incomplete.json`).
- `.gitignore`: tells Git which files to skip. You do not need to edit it.
- `README.md`: this file. You will replace it with your own README (see below).

## Your First 15 Minutes

1. Open your `cs300-assignment-3` folder in VS Code.
2. Choose **Terminal > New Terminal** and run `node harness.js`. You should see the "Starter ready" message. It confirms your setup only; it is not a passing test.
3. Open `SCENARIOS.md` and pick one scenario.
4. Open your scenario's dataset in `data/` and read the eight records.
5. Open the submission template and fill in Plan Before Building, including the seven-row function table.
6. Replace everything in this README with your name and your scenario. This guide stays in your extracted starter folder.
7. Commit with the message `Add starter files and choose scenario` and push.
